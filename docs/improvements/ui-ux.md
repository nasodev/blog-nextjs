## 검증

- lint·Next route typegen·TypeScript 검사 통과.
- `tests/ui-ux.browser.spec.ts`: 느린 검색 응답, 입력 유지, 포커스 순환/복원, 실패 안내, 320px 메뉴, 본문 넘침, 동작 감소 회귀 검사.
- 통합 워크트리에서 화면과 E2E를 검증하고 최종 보고서에 결과를 기록한다.

## 후속 제안

- 실제 방문자 데이터가 쌓이면 모바일 LCP/CLS/INP를 측정해 큰 커버와 긴 페이지 간격을 조정한다. 측정 없이 성능 점수를 추정하지 않았다.
- 한국어 목록의 잔여 영문 문구, 소개 본문 번역은 콘텐츠 편집 범위로 별도 정리할 수 있다.
- WCAG 전체 준수나 모든 스크린 리더 호환성을 인증한 것은 아니다. 이번 범위는 확인된 키보드·모바일 사용 문제다.
